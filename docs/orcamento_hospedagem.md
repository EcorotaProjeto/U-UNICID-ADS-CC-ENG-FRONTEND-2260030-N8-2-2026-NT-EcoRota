## Justificativa

- **Hospedagem: Vercel, no plano Hobby.** Para uma equipe independente, o mais importante é manter o custo fixo perto de zero. O plano Hobby é gratuito, tem https incluso e publica o site automaticamente a cada atualização no GitHub, que é o controle de versão usado pela equipe. Ele cabe no EcoRota porque o site é estático e o uso é educacional, sem fins comerciais, que é a condição do plano. O GitHub Pages também seria gratuito, mas o Vercel já está configurado para o projeto. Limites a observar: o Hobby tem 1 assento de deploy e não pode ser usado para fins comerciais.
- **Domínio: ecorota.com.br no Registro.br.** O .com.br passa mais confiança ao público brasileiro, e o Registro.br é o registrador oficial, com o mesmo preço no registro e na renovação (R$ 40,00). Nos outros, a renovação é mais cara (na Locaweb, R$ 108,90).
- **Plano de crescimento:** se o projeto precisar de e-mail com o próprio domínio ou de servidor para guardar os pedidos de coleta, a melhor opção é a Hostinger, com suporte em português e 100% da energia dos data centers compensada com eletricidade renovável.

**Custo total: R$ 40,00 por ano.**
